## 🎯 Стандарт оформления

### Структура каждой демо-страницы

```
1. @page директива
2. Главная SgCard с Title и Subtitle
3. Разделы с h2 заголовками
4. Примеры компонентов
5. Таблицы свойств (PropertyTable)
6. Примеры кода (обязательно)
```

### Адаптивная сетка

Все примеры используют класс `demo-grid-adaptive`:
- **Desktop (>1200px)**: 2 колонки (примеры + свойства)
- **Tablet (900-1200px)**: 2 колонки (узкие)
- **Mobile (<900px)**: 1 колонка (стопка)

### Примеры кода

Каждая страница содержит раздел "Примеры кода" с:
- Базовым использованием компонента
- Использованием с событиями
- Продвинутыми примерами (если применимо)
